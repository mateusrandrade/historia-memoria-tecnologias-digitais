## Este repositório também faz parte da disciplina

O GitHub será utilizado não apenas para disponibilizar informações da disciplina, mas também como ambiente de aprendizagem sobre documentação, organização de arquivos, repositórios e versionamento.

Não é necessário possuir conhecimento prévio sobre GitHub. Inicialmente, os estudantes precisarão apenas saber navegar pelo repositório, localizar os documentos e acompanhar as atualizações realizadas ao longo do semestre.
